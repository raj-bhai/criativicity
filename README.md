
# 🎓 Online Course Selling Platform  

A responsive **Online Course Selling Platform** built with **React**, where users can purchase, access courses, and receive a certificate upon completion. While it currently focuses on video editing courses, the platform can be customized to sell any type of online courses. It features a modern, user-friendly interface optimized for all devices.  

## 🚀 Features  
- User authentication  
- Purchase and access courses  
- Watch video lessons  
- Certificate upon course completion  
- Fully responsive design
